四个问题与修法

「直译」状态下每一条都会当场现形；数字是算出来的，不是感觉。

  1. 1 · 深色下 #862C2C 不能当文字色

    对底 #1B1B19 只有 1.98:1，连图标门槛 3:1 都不到；当按钮底色反而极好（白字 8.71:1）。修法：拆成两个角色——填充 #862C2C，墨色 #DA9090（对底 6.04:1）。

    直译 1.98:1修复 6.04:1
  2. 2 · 暖灰 SurfaceAlt 压在粉底上显脏

    #EFEDE6 偏黄，压在 #F5EBEB 上带绿味；且和底色只差 1.0:1，悬停态等于没有。修法：#F0E2E2（对底 1.08、对白 1.26），暗色用 #332B2B。配套把次要文字 #6B6A66 → #5A5853，否则压在新 alt 上只有 4.3:1。

    直译 1.00:1修复 1.08:1
  3. 3 · 强调色和危险色撞车

    DangerBrush #C73A39 与 #A83838 色相差仅 0.4°，灰度下亮度也几乎一样（1.24:1），主按钮和失败标记无法区分。修法：危险色挪到焦橙 #92400E（色相差 23°，对粉底 6.07:1），暗色 #FFA94D；警告随之挪到 #6E5A00 / #E8D44D，三种状态色各自隔 20° 以上。

    直译 Δ0.4°修复 Δ23°
  4. 4 · AccentFaintBrush 在粉底上失效

    它是强调色 9% 叠底色：旧底是暖灰能叠出淡紫，新底本身就是强调色的淡色，叠出来对底只有 1.03:1。修法：透明度 9% → 14%（只用于白卡片内），大面积一律不用它——首页拖放区改为「白面 + 酒红 2px 描边」，切换到「直译」看它塌掉的样子。

    直译 1.03:1修复 1.17:1

浅色调阶（对底色 #F5EBEB 的对比）

修完后每一档都和左右邻居差至少一档，没有两档贴在一起。
