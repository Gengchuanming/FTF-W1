在 Visual Studio 中:
1. 打开 `Filee.slnx`

3. 选择 "Pack"
4. 选择 MSIX 打包类型
5. 等待完成

**输出位置**: `AppPackages\FileeFTF_*.msix`

## 常见问题

### ❓ 需要什么工具？
- ✅ .NET 8.0 SDK
- ✅ Visual Studio 2022 (或 MSBuild)
- ✅ Windows 10 1809+ 或 Windows 11

### ❓ 打包需要多长时间？
- 检查环境: 10秒
- 发布应用: 2-5分钟
- 准备资源: 1分钟
- **总计**: 约 5-10分钟

### ❓ 在哪里找到 MSIX 文件？
打包完成后，MSIX 文件位于:
```
AppPackages\FileeFTF_1.0.0.0_x64_Release.msix
```

### ❓ 如何签名 MSIX 包？
```powershell
signtool sign /f certificate.pfx /p password AppPackages\FileeFTF_*.msix
```

### ❓ 上传到 Store
登录: https://partner.microsoft.com/dashboard
