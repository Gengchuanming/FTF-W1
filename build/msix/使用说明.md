# Filee MSIX 打包快速指南

## 概述

本文档提供了将 Filee 应用打包成 MSIX 格式的详细步骤,以便发布到 Microsoft Store。

## 快速开始 (3步)

### 1️⃣ 运行快速打包脚本
```powershell
cd c:\Users\耿\FTF-W1
.\build\msix\quick-pack.ps1
```

### 2️⃣ 在 Visual Studio 中打包
- 打开 `Filee.slnx`
- 右键点击 `src/Filee.App/Filee.App.csproj`
- 选择 "打包" (Pack)
- 按向导提示操作

### 3️⃣ 签名并上传到 Store
```powershell
# 签名 MSIX 包
signtool sign /f certificate.pfx /p password AppPackages\FileeFTF_*.msix

# 上传到 Microsoft Store
# 登录 https://partner.microsoft.com/dashboard
```

## 详细步骤

### 步骤 1: 准备工作

确保安装了以下工具:
- ✅ Windows 10 1809+ 或 Windows 11
- ✅ .NET 8.0 SDK
- ✅ Visual Studio 2022 (推荐)
- ✅ 有效的代码签名证书 (可选,Store会提供)

### 步骤 2: 配置项目

已为你创建了以下文件:
- ✅ `build/msix/AppxManifest.xml` - MSIX清单文件
- ✅ `build/msix/quick-pack.ps1` - 快速打包脚本
- ✅ `build/msix/pack-msix.ps1` - 完整打包脚本
- ✅ `build/msix/README.md` - 详细文档
- ✅ `src/Filee.App/app.msix.props` - 项目配置

### 步骤 3: 发布应用

在 Visual Studio 中:

1. **打开解决方案**
   ```
   Filee.slnx
   ```

2. **选择配置**
   - Configuration: Release
   - Platform: x64

3. **右键点击项目**
   - 在解决方案资源管理器中找到 `src/Filee.App`
   - 右键点击 → "打包" (Pack)

4. **配置打包向导**
   ```
   - 打包类型: MSIX
   - 目标平台: Windows 10 或 Windows 11
   - 平台: x64
   - 应用类型: 桌面应用
   - 体系结构: Desktop
   ```

5. **等待完成**
   - 打包进度显示完成
   - 输出位置: `AppPackages\FileeFTF_1.0.0.0_x64_Release.msix`

### 步骤 4: 签名 MSIX 包

如果你有证书:

```powershell
# 使用证书文件签名
signtool sign /f certificate.pfx /p yourpassword AppPackages\FileeFTF_*.msix

# 或使用时间戳服务器
signtool sign /f certificate.pfx /p yourpassword /t http://timestamp.digicert.com AppPackages\FileeFTF_*.msix
```

如果你没有证书,上传到 Store 后Microsoft会自动签名。

### 步骤 5: 上传到 Microsoft Store

1. **登录 Partner Center**
   - 访问: https://partner.microsoft.com/dashboard

2. **创建应用**
   - 点击 "创建新应用"
   - 选择 "免版税应用"
   - 输入应用信息:
     - 名称: Filee FTF
     - 品牌: FileeFTF
     - 版本: 1.0.0.0

3. **填写应用详情**
   - 简短描述
   - 详细描述 (支持多语言)
   - 应用分类
   - 年龄分级
   - 隐私策略 URL
   - 许可协议 URL

4. **上传 MSIX 包**
   - 进入 "管理" → "应用包"
   - 上传 `AppPackages\FileeFTF_*.msix`
   - 确认信息无误

5. **提交审核**
   - 检查所有必填字段
   - 点击 "提交"
   - 等待审核 (1-7个工作日)

## 常见问题速查

### ❓ 打包失败怎么办?
**解决**:
1. 检查是否选择了 Release 配置
2. 确认 .NET SDK 已安装: `dotnet --version`
3. 查看错误日志

### ❓ MSIX 包在哪里?
**位置**:
- 默认: `AppPackages\FileeFTF_1.0.0.0_x64_Release.msix`
- 可以在脚本中修改输出目录

### ❓ 如何更新版本号?
**方法1**: 修改 `AppxManifest.xml`
```xml
<Identity Version="1.0.0.1" />
```

**方法2**: 使用完整打包脚本
```powershell
.\build\msix\pack-msix.ps1 -Version 1.0.0.1
```

### ❓ 应用权限如何配置?
编辑 `build/msix/AppxManifest.xml`:
```xml
<Capabilities>
  <Capability Name="documentsLibrary" />
  <Capability Name="internetClient" />
  <!-- 添加或删除需要的权限 -->
</Capabilities>
```

### ❓ 如何测试打包的应用?
```powershell
# 安装 MSIX 包
Add-AppxPackage -Path "AppPackages\FileeFTF_*.msix"

# 运行应用
ftf.exe
```

### ❓ 需要什么证书?
- **开发阶段**: 可用自签名证书
- **发布到 Store**: Microsoft提供免费证书
- **其他渠道**: 需要购买代码签名证书
